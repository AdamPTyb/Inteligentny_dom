Projekt zaliczeniowy z Programowania Obiektowego wykonany w języku Python.

Opis projektu:
aplikacja symuluje system inteligentnego domu umożliwiający zarządzanie urządzeniami.

Program pozwala:
dodawać urządzenia,
wyświetlać ich status,
włączać urządzenia,
zmieniać ustawienia,
symulować działanie inteligentnego domu.

Zastosowane elementy OOP,
w projekcie wykorzystano:
klasy i obiekty,
dziedziczenie,
klasy abstrakcyjne,
interfejsy,
enkapsulację,
polimorfizm.

Struktura projektu:
devices,
device,
smart_socket,
air_conditioner,
camera,
smart_home,
interfaces,
switchable,
adjustable,
